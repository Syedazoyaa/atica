# Changelog

All notable changes are documented here. ATICA follows [Semantic Versioning](https://semver.org/).

## 0.8.0 - Integrated release (pre-1.0)

First implementation of the full Product Specification.

* M01 unit engine with 16 categories and temperature strategies.
* M02 custom units with isolated registries and JSON persistence.
* M03/M04 packaging hierarchies, validation, quantity conversion and breakdown.
* M05/M06 material requirements, batches, safe formulas, yield, scrap and wastage.
* M07 purchasing with MOQ, order multiples and supplier rules.
* M08 CSV and optional Excel bulk processing with row-level errors.
* M09 structured validation results; M10 per-operation rounding policies.
* Versioned configuration file (`AticaConfig`).
* PySide6 desktop application preview.

Not yet done before 1.0: TestPyPI/PyPI publication, Windows installer build, review of the public API for stability.
